Desain ulang website Portal Nagari Sungai Pinang - Design System Komprehensif

OVERVIEW:
Website portal nagari modern dengan fitur lengkap: berita, Profile, layanan, UMKM, fasilitas, dokumentasi publik, GIS, . Responsive mobile-first, navigasi intuitif, dan data-driven.

HALAMAN UTAMA (HOME):
1. Hero Section: Background gradient, logo, judul besar, deskripsi, foto kepala nagari (responsive: besar di desktop, hidden di mobile)
2. Popup WhatsApp AI Agent: Animasi, muncul otomatis, info layanan surat 24 jam
3. Statistik Nagari: 6 card animasi bergantian (jumlah penduduk, luas wilayah, tahun pembentukan, ketinggian, anggaran, fasilitas)
4. Layanan Unggulan: Card horizontal scroll, responsive, info layanan surat + estimasi waktu + status gratis
5. Berita Populer: Slideshow horizontal, card responsive, hanya judul di mobile
6. UMKM Unggulan: Grid card responsive (2 kolom mobile, 3+ desktop)
7. Fasilitas Publik: Grid card responsive
8. Section Hubungi & Ikuti Kami: Card kontak, sosial media icons
9. Struktur Pemerintahan: Card staff dengan foto, nama, jabatan
10. Footer: Contact info, navigasi, social media

HALAMAN SEKUNDER:
- Berita: Layout grid, search, filter kategori, pagination, detail view
- UMKM: Directory dengan kategori, filter, search, detail produk
- Fasilitas: List dengan kategori, search, map view
- Layanan Surat: Form builder, estimasi biaya, timeline proses
- PPID: Document library dengan kategori, download, search
- Profil: Multi-section (visi-misi, sejarah, struktur, galeri)
- Pengaduan: Form dengan kategori, tracking status
- GIS: Interactive map dengan locations
- Proyek: Timeline atau grid view dengan progress
- Public Data: Dashboard dengan charts, analytics

DESIGN SYSTEM:
- Color: Primary green (#10b981), Secondary colors, Neutral grays
- Typography: Header serif (Playfair Display), Body sans-serif (Montserrat)
- Components: Button, Card, Input, Select, Table, Modal, Carousel, Breadcrumb
- Spacing: 8px grid system
- Icons: Modern line icons (Lucide React style)
- Shadows: Subtle elevation shadows
- Animations: Smooth transitions, entrance animations, hover states

RESPONSIVE BREAKPOINTS:
- Mobile: < 768px (hidden elements, single column, smaller text)
- Tablet: 768px - 1024px (optimized spacing, 2-3 columns)
- Desktop: > 1024px (full layout, 3-4 columns, large imagery)

FEATURES:
- Dynamic menu dari API (/navigation-menu)
- Dynamic content dari 15+ endpoints API
- Form handling untuk layanan surat & pengaduan
- Search & filter pada berita, UMKM, fasilitas
- Pagination & infinite scroll
- Document download
- Map integration (GIS)
- AI WhatsApp integration
- Social media links
- Contact form validation

INTERACTIONS:
- Smooth hover states pada card & buttons
- Animated counters pada statistik
- Carousel auto-play dengan manual controls
- Modal untuk detail/preview
- Toast notifications untuk success/error
- Loading skeletons
- Empty states dengan helpful messages

ACCESSIBILITY:
- Semantic HTML
- ARIA labels
- Keyboard navigation
- Color contrast compliance
- Alt text untuk images
